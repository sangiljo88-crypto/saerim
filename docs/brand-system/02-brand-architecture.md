# 새림 브랜드 아키텍처

> 새림은 하나의 인프라 위에 여러 브랜드를 운영한다.
> 브랜드가 늘어나도 이 구조는 바뀌지 않는다.

## 1. 구조: Branded House + Sub Brands

```
                ┌─────────────────────────────┐
                │        유한회사 새림          │
                │   (식품 인프라 · 마스터 브랜드)  │
                └──────────────┬──────────────┘
        ┌──────────────────────┼──────────────────────┐
        ▼                      ▼                      ▼
┌───────────────┐     ┌───────────────┐     ┌───────────────┐
│ 전국국밥거래소   │     │    육식노트     │     │  (미래 브랜드)  │
│ 국탕류 B2B 채널 │     │ 뒷고기·특수부위  │     │   슬롯 확장     │
│ 국밥집 원료 직송 │     │ 소비자·매장 채널 │     │               │
└───────────────┘     └───────────────┘     └───────────────┘
```

## 2. 역할 정의

| 브랜드 | 역할 | 고객 | 말투 |
|--------|------|------|------|
| **새림** | 생산·품질·OEM을 책임지는 마스터 브랜드. 신뢰의 원천 | B2B 바이어, 파트너사 | 절제된 기업 언어 |
| **전국국밥거래소** | 국탕류(돈두·내장·탕육) 전문 공급 채널 | 국밥·순댓국 매장 | 실무적, 거래 중심 |
| **육식노트** | 뒷고기·특수부위 전문 채널 | 고기 전문점, 일반 소비자 | 감각적, 발견의 재미 |

## 3. 표기 규칙

- 서브 브랜드가 등장할 때는 항상 **"새림의 브랜드"**임이 드러나야 한다.
  - 예: "전국국밥거래소 by 새림" / "새림이 만드는 육식노트"
- 웹사이트·포장·명함 등 모든 접점에서 마스터 브랜드 로고가 함께 노출된다.
- 서브 브랜드는 각자 대표 색을 가질 수 있으나, 새림 사이트 안에서는 새림 디자인 시스템을 따른다.

## 4. 공장 브랜딩 (Factory as Brand)

각 공장은 하나의 브랜드처럼 다룬다. 이름·역할·상징 문장을 갖는다.

| 공장 | 코드 | 역할 | 상징 문장 |
|------|------|------|----------|
| **군산공장** | GUNSAN | 본사 · 돼지 부산물 (돈두·내장류) 원스톱 생산 | "국밥 한 그릇의 기준이 시작되는 곳" |
| **김제공장** | GIMJE | 돼지 부산물 세척·가열 전문 라인 | "가장 까다로운 공정을 도맡는 곳" |
| **용인공장** | YONGIN | 햄·육가공 OEM/B2B 생산 | "브랜드의 주문이 제품이 되는 곳" |

- 사이트 구조: `/factory` (전체 지도) → `/factory/gunsan` `/factory/gimje` `/factory/yongin`
- 공장이 추가되면 DB에 레코드 하나를 추가하는 것으로 끝난다. 페이지는 자동 생성된다.

## 5. 확장 원칙

1. 새 브랜드·새 공장은 **데이터 추가**로 반영한다. 구조 변경 금지.
2. 서브 브랜드가 독립 사이트를 갖게 되면, 새림 사이트는 그 허브(포털) 역할을 유지한다.
3. 브랜드 수가 5개를 넘으면 BRAND 페이지를 카테고리형으로 전환한다 (그 전까지는 스토리형 유지).
