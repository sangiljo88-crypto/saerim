# 새림 UI/UX 디자인 시스템

> 화이트 기반 미니멀. 스크롤을 내릴수록 신뢰가 쌓인다.
> 모든 페이지는 이 토큰과 규칙만 사용한다.

## 1. 컬러 토큰

| 토큰 | 값 | 용도 | 비율 |
|------|-----|------|------|
| `paper` | `#FFFFFF` | 기본 배경 | 60% |
| `paper-warm` | `#FAFAF8` | 섹션 구분 배경 | 20% |
| `ink-900` | `#111417` | 헤드라인, 본문 강조 | 10% |
| `ink-600` | `#4B5563` | 본문 | 6% |
| `ink-400` | `#9CA3AF` | 캡션, 라벨 | 2% |
| `line` | `#E5E7EB` | 헤어라인 구분선 | - |
| `accent` | `#B42318` | 포인트 (새림 레드) — CTA·강조 숫자에만 | ≤2% |
| `trust` | `#0E4D45` | 신뢰 딥그린 — 인증·품질 뱃지에만 | ≤1% |

규칙: 그라데이션·유리효과·그림자 금지. 구분은 여백과 1px 헤어라인으로만 한다.
(예외: 사진 위 텍스트 가독성을 위한 단색 오버레이는 허용)

## 2. 타이포그래피

- 폰트: **Pretendard** (시스템 폴백: Apple SD Gothic Neo, Noto Sans KR)
- 영문 라벨: 같은 폰트, `tracking-[0.18em]` 대문자

| 스케일 | 크기 | 용도 |
|--------|------|------|
| `display` | clamp(2.5rem→4.5rem) / 1.1 / 700 | Hero 한 줄 메시지 |
| `h1` | 2.25rem / 1.2 / 700 | 페이지 제목 |
| `h2` | 1.75rem / 1.3 / 700 | 섹션 헤드라인 |
| `h3` | 1.125rem / 1.4 / 600 | 카드 제목 |
| `body` | 1.0625rem / 1.75 / 400 | 본문 |
| `label` | 0.8125rem / 1.4 / 600 | 영문 킥커, 캡션 |

규칙: 한 섹션에 헤드라인은 하나. 본문 최대 폭 `65ch`.

## 3. 레이아웃

- 최대 폭: 텍스트 섹션 `max-w-4xl`, 그리드 섹션 `max-w-6xl`, Hero 풀블리드
- 섹션 수직 패딩: 모바일 `py-20`, 데스크톱 `py-32` — 여백이 신뢰를 만든다
- 그리드: 2·3열만 사용 (4열 이상 금지 — 카탈로그가 아니라 브랜드다)
- 모서리: 사진 `rounded-2xl`, 카드 `rounded-xl`, 버튼 `rounded-full`

## 4. 컴포넌트 규칙

| 컴포넌트 | 규칙 |
|----------|------|
| `Kicker` | 영문 대문자 라벨 + 헤어라인. 모든 섹션의 시작점 |
| `SectionTitle` | 헤드라인 + 선택적 한 줄 설명 |
| `StatBlock` | 큰 숫자(accent) + 라벨. 신뢰 증명 전용 |
| `CtaPrimary` | ink-900 배경 흰 글자, rounded-full |
| `CtaSecondary` | 1px 테두리, 투명 배경 |
| `NextStory` | 페이지 하단 고정 패턴: "다음 이야기 → OOO" |
| `QualityFlow` | 품질 8단계 인터랙티브 스텝퍼 (클릭/스크롤 반응) |

## 5. 모션

- 원칙: 눈에 띄지 않을 만큼만. 장식적 애니메이션 금지.
- 등장: `opacity 0→1` + `translateY 16px→0`, 0.6s ease-out, 뷰포트 진입 시 1회
- Hero 미디어: 12s 스케일 1.0→1.05 슬로우 줌 (영상 대체 슬롯)
- `prefers-reduced-motion` 존중 필수

## 6. 사진 규칙

- 공정·설비·원료 사진 우선. 연출된 스톡 이미지 금지.
- 사진 위 텍스트는 `ink-950/55` 단색 오버레이 위에만.
- 제품 사진(썸네일) 비율 1:1 정사각형, 공장·Hero 사진 16:9 고정.

## 7. 접근성·품질 기준

- 명도 대비 WCAG AA 이상 (ink-600 이상만 본문 사용)
- 모든 인터랙션 키보드 접근 가능
- 이미지 alt 필수, 장식 이미지는 `alt=""`
