# 새림 UI/UX 디자인 시스템

> 아이보리 바탕의 미니멀 — 녹색으로 신뢰를, 금색으로 온기를. 스크롤을 내릴수록 신뢰가 쌓인다.
> 모든 페이지는 이 토큰과 규칙만 사용한다.

## 1. 컬러 토큰 (브랜드 아이덴티티 1.0 · 2026-10-24)

> 아이보리로 여백을 만들고, 녹색으로 브랜드를 인식하게 하고, 금색은 작은 강조에만 쓴다. 비율 배경 60 · 녹색 30 · 강조 10.

| 토큰 | 값 | 브랜드 이름 | 용도 |
|------|-----|------|------|
| `paper` | `#F6F3E9` | Ivory | 기본 배경 (body) |
| `paper-warm` | `#E8EDE6` | Mist | 섹션 구분·보조 배경, 배지 바탕 |
| `ink-900` | `#123F2E` | Deep | 헤드라인, CTA 배경, 푸터 면 |
| `ink-600` | `#202C25` | Ink | 본문 |
| `ink-400` | `#5F6E64` | — | 캡션, 라벨 (아이보리 위 4.9:1) |
| `line` | `#D6DBD2` | — | 헤어라인 |
| `accent` | `#1E583A` | Forest | 강조 글자·연도·번호·호버 (구 레드 포인트 대체) |
| `gold` | `#D4AF37` | Gold | 불릿·짧은 구분선(`.gold-rule`)·역상 링크 호버. **작은 본문 글자에 쓰지 않는다** (아이보리 위 2.1:1) |
| `trust` / `trust-soft` | `#1E583A` / `#E8EDE6` | — | 인증·품질 배지 |
| `danger` | `#B42318` | — | 폼 오류·필수 표시·관리자 미처리 문의 전용 |

원색 토큰 `forest · deep · leaf · gold · ivory · mist`도 같은 값으로 등록돼 있다. 로고 원본에서 추출한 색은 Forest·Deep·Leaf·Gold, 나머지는 가이드의 확장색.

규칙: 그라데이션·유리효과·그림자 금지. 녹색 배경의 글자는 흰색. 흰 카드(`bg-white`)는 아이보리·미스트 위에 그대로 쓴다.

## 2. 타이포그래피

- 본문·제품명·규격·UI: **Pretendard** (CDN 다이내믹 서브셋, 시스템 폴백: Apple SD Gothic Neo, Noto Sans KR)
- 브랜드 문장: **고운바탕 Regular** (`src/fonts/`, SIL OFL, `next/font/local` → `font-batang`). `BrandStatement` 컴포넌트를 통해서만 쓰고, 한국어일 때만 적용된다 — 한자 글리프가 없어 영어·중국어는 Pretendard로 둔다.
- 고운바탕 사용처(전부): HOME Hero H1 · WHY 인용문·캠페인 문구·시그니처 · BRAND 약속 문장·시그니처 · OEM 시그니처. 페이지 대제목에 일괄 적용하지 않는다.
- 영문 라벨(kicker): Pretendard, `tracking-[0.18em]` 대문자

| 스케일 | 크기 | 용도 |
|--------|------|------|
| `display` | clamp(2.5rem→4.5rem) / 1.1 / 700 | 페이지 대제목 (Hero H1은 고운바탕용으로 clamp(2.125rem→3.5rem) / 1.2) |
| `h1` | 2.25rem / 1.2 / 700 | 페이지 제목 |
| `h2` | 1.75rem / 1.3 / 700 | 섹션 헤드라인 |
| `h3` | 1.125rem / 1.4 / 600 | 카드 제목 |
| `body` | 1.0625rem / 1.75 / 400 | 본문 |
| `label` | 0.8125rem / 1.4 / 600 | 영문 킥커, 캡션 |

규칙: 한 섹션에 헤드라인은 하나. 본문 최대 폭 `65ch`.

## 2-1. 로고

- 원본: `새림로고(20261024)최신.ai` p2(플랫)·p5(단색)·p6(역상)에서 벡터 추출. `public/images/logo/` — `logo-{flat,mono,reverse}.svg`, `symbol-{flat,mono,reverse}.svg`, `logo-flat.png`, `symbol-flat.png`
- 헤더: 심벌(36px) + 별도 "SAERIM" 텍스트. 락업을 재조합하지 않는다.
- 푸터: Deep 면 위 역상 락업 256px (최소 가로폭). md 미만은 심벌 + 회사명 텍스트.
- 파비콘 `src/app/icon.svg` = 심벌 플랫. Organization 구조화 데이터 `logo` = `logo-flat.png`.
- 보호 공간은 심벌 높이의 1/4 이상. 비율 변형·색 치환·그림자·사진 위 배치 금지.
- 보조 그래픽 `public/images/brand/prepared-flow.svg` — 한 면에 한 번, 정보 영역을 가리지 않게. 현재 OEM 시그니처 섹션에만.

## 3. 레이아웃

- 최대 폭: 텍스트 섹션 `max-w-4xl`, 그리드 섹션 `max-w-6xl`. HOME Hero는 왼쪽 메시지·오른쪽 실제 공장 전경, 모바일에서는 세로로 쌓는다.
- 아이덴티티 설명은 BRAND에서 원본 로고와 ‘바른 준비’의 의미를 함께 보여준다. 큰 심벌로 HOME 전경을 대체하지 않는다.
- 섹션 수직 패딩: 모바일 `py-20`, 데스크톱 `py-32` — 여백이 신뢰를 만든다
- 그리드: 2·3열만 사용 (4열 이상 금지 — 카탈로그가 아니라 브랜드다)
- 모서리: 사진 `rounded-2xl`, 카드 `rounded-xl`, 버튼 `rounded-full`

## 4. 컴포넌트 규칙

| 컴포넌트 | 규칙 |
|----------|------|
| `Kicker` | 영문 대문자 라벨 + 헤어라인. 모든 섹션의 시작점 |
| `SectionTitle` | 헤드라인 + 선택적 한 줄 설명 |
| `StatBlock` | 큰 숫자(accent) + 라벨. 신뢰 증명 전용 |
| `CtaPrimary` | ink-900 배경 흰 글자, rounded-full |
| `CtaSecondary` | 1px 테두리, 투명 배경 |
| `NextStory` | 페이지 하단 고정 패턴: "다음 이야기 → OOO" |
| `QualityFlow` | 품질 8단계 인터랙티브 스텝퍼 (클릭/스크롤 반응) |
| `FactoryVideo` | 공식 영상 썸네일·재생 버튼·YouTube 링크. 클릭 후 개인정보 보호 강화 iframe을 생성한다. 홈·공장 목록·상세에서 같은 지사 영상을 연결한다. |

## 5. 모션

- 원칙: 눈에 띄지 않을 만큼만. 장식적 애니메이션 금지.
- 등장: `opacity 0→1` + `translateY 16px→0`, 0.6s ease-out, 뷰포트 진입 시 1회
- HOME Hero 전경은 정지 사진을 기본으로 한다. 관리자 지정 동영상은 컨트롤을 제공하고 자동 재생하지 않는다.
- `prefers-reduced-motion` 존중 필수

## 6. 사진 규칙

- 공정·설비·원료 사진 우선. 연출된 스톡 이미지 금지.
- 사진 위 텍스트는 `ink-950/55` 단색 오버레이 위에만.
- 제품 사진(썸네일) 비율 1:1 정사각형, 공장 사진 16:9, HOME Hero 전경 16:10.
- 지사 영상은 16:9를 기본으로 하되 모바일 플레이어 높이는 YouTube 최소 크기에 맞춰 200px 이상으로 유지한다.

## 7. 접근성·품질 기준

- 명도 대비 WCAG AA 이상 (ink-600 이상만 본문 사용)
- 모든 인터랙션 키보드 접근 가능
- 이미지 alt 필수, 장식 이미지는 `alt=""`
