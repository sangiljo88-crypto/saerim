# 새림 슬로건 · 카피라이팅 시스템

> 근거 이론: 간다 마사노리 『돈이 되는 말의 법칙』, 최홍희 상세페이지 방법론, 페이머스 브랜딩.
> 이 문서는 01-brand-philosophy(철학)에서 나온 말을 "팔리는 말"로 완성하는 규칙이다.

## 1. 에센스 — 한 단어

**준비 (準備)**

새림의 모든 말은 이 한 단어에서 나온다. 파는 회사가 아니라 준비하는 회사.
(페이머스: "버릴수록 진해진다" — 12개 단어를 버리고 하나만 남긴 결과)

## 3. 카피 작성 규칙 (모든 페이지 공통)

1. **주어는 고객.** "새림은 ~합니다"보다 "사장님은 ~하세요"가 먼저 온다.
   - (X) 새림은 당일 출고합니다 → (O) 오전 10시에 주문하세요. 저녁 장사 전에 도착합니다.
2. **고통에서 시작한다 (New PASONA의 P·A).** 제품·회사 자랑으로 문단을 시작하지 않는다.
   장면은 오감으로: "매일 아침 머릿고기 상태부터 확인하시죠?"
3. **숫자로 증명한다 (Toyota 원칙 + 페이머스 넘버).** 형용사 하나를 숫자 하나로 바꾼다.
   - 22년(2004~), 3개 공장, 8단계, 10시 이전 주문 당일 출고, -18℃
4. **특징은 한 번에 2가지, 20초 안에.** (간다 T-2) 셋 이상 늘어놓지 않는다.
5. **증거는 고객의 입으로.** (간다 L-27) 후기·거래처 사례를 확보하는 대로 카피보다 앞세운다.
6. **글의 목표는 정보가 아니라 감정.** 각 페이지가 남길 감정 한 가지를 먼저 정한다:
   HOME=안심 / WHY=존경 / PRODUCT=확신 / QUALITY=신뢰 / OEM=설렘 / CONTACT=환대
7. **기원으로 닫는다.** 거래의 끝은 감사가 아니라 고객이 잘되기를 비는 말이다.

## 4. 제품 카피 공식 (상세페이지)

최홍희 3요소를 제품 DB 필드에 대응:

| 요소 | 필드 | 규칙 |
|------|------|------|
| 원메시지 (스테이크) | summary | 고객 삶의 변화 한 문장. "~할 수 있는 / ~하지 않아도 되는 ○○" 문형 |
| 스토리 (시나리오) | story | 고객의 의심을 녹이는 2~3문장. 사장님의 하루 장면에서 시작 |
| 보너스 (가니쉬) | features 마지막 항목 | "오, 좋은데?" 의외의 덤 1개 |

- USP는 '우리 피셜' 금지 — 거래처·후기에서 나온 말로 뽑는다.
- 원메시지와 스토리는 반드시 같은 고통을 가리킨다 (비침 없는 원피스에 먼지 스토리 금지).

## 5. 금지어

- 근거 없는 최상급: 최고, 최상, 프리미엄 (숫자·공정으로 대체)
- 남발 금지: 마스터 슬로건은 HOME Hero에서만, 만트라는 접수 완료에서만
- "그냥", "다양한", "여러 가지" — 잊히는 말 (페이머스 제7명제)
