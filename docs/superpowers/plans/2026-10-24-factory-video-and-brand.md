# 공장 전경·브랜드 소개·지사 영상 반영

사용자 승인 방향: 첫 화면은 실제 회사 전경으로, 브랜드 소개는 아이덴티티의 의미를 자연스럽게 설명한다. 제공된 김제·용인 소개영상을 홈페이지에서 볼 수 있게 한다.

## 구현

1. 홈 Hero의 큰 심벌을 기존 회사 전경으로 교체한다. 왼쪽 브랜드 문장과 문의 버튼, 오른쪽 실제 전경 구성을 사용한다. 하단 중복 전경은 제거한다.
2. BRAND에 원본 로고와 ‘좋은 재료, 바른 먹거리’, ‘바른 준비’ 설명을 추가한다. 재료 선택→가공·포장→공급 흐름으로 회사·제품의 공통 약속을 설명한다.
3. `src/lib/factory-videos.ts`에 사용자가 제공한 두 영상만 공장 slug와 연결한다. 김제 `4pXO82VN6bQ`, 용인 `Y2fNzjaCV54`. 군산에는 기존 사진을 유지한다.
4. 홈페이지에 두 영상 갤러리, 공장 목록에는 해당 공장 영상, 상세 페이지에는 개별 영상을 배치한다. 외부 플레이어는 클릭 후 생성하고 새 탭 YouTube 링크를 함께 제공한다.
5. 한국어·영어·중국어 설명과 재생 UI를 제공한다. DB·관리자 설정·제품 사실 정보는 변경하지 않는다.

## 검증 및 전달

- ESLint, TypeScript, 프로덕션 빌드, 기존 SEO 검사.
- 데스크톱·모바일에서 전경과 브랜드 설명, 지사별 영상 연결 확인.
- 클릭 전 iframe 미생성, 클릭 후 올바른 영상 iframe, 키보드 접근과 실제 YouTube 플레이어 상태 확인.
- 기존 PR #5에 함께 반영하고 로컬 미리보기 제공. 병합·배포는 별도 승인 단계에 둔다.
